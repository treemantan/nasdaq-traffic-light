# MAG7 企业资本关系图谱

## 目标

该板块追踪的是 MAG7 公司自身对外配置资本所形成的产业链关系，不是用户组合对 MAG7 股票的持仓暴露。

图谱重点回答：

- 大型科技平台的资本正在流向哪些 AI 模型公司、云平台、半导体、光通信和数据中心基础设施公司？
- 某条产业链关系属于已确认股权投资、附条件投资权利、战略合作，还是只能看到聚合金额的财务披露？
- 这些关系是否为 ETF 行业暴露和单一股票事件复核提供了额外线索？

## 当前实现

第一版使用人工审计的官方披露快照，数据来自公司官方公告和 SEC 文件。每条具名记录包含：

- 投资方与 ticker
- 目标公司与 ticker；非上市公司标记为 `PRIVATE`
- 关系类型
- 已披露金额或投资条件
- 披露日期
- 官方来源链接
- 置信度
- 产业链主题

报告将具名连接与聚合披露分开显示。例如，Alphabet 在 Form 10-K 中披露非上市股权证券的聚合账面价值，但未公开完整底层名单，因此不能把总额直接归属到某一家 AI 公司。

## 使用边界

- 图谱是公开披露关系的可识别下限，不是 MAG7 完整证券持仓表。
- 私募投资、子公司投资和商业合作不一定逐项披露。
- 战略合作不等同于已确认股权持仓。
- 聚合财务披露只能用于观察资本配置规模，不能伪造底层名单。
- 关系图谱用于产业链研究与事件复核，不构成交易建议。

## 后续可扩展方向

可以基于 SEC EDGAR API 增加增量抓取与披露日期检查。SEC API 不需要 API key，但不同公司可能通过 10-K、10-Q、8-K、13F 或官方公告披露不同颗粒度的信息，因此自动化结果仍需保留来源链接和人工复核状态。
