# 方法论：评分、相似环境与 MAD 自适应校准

## 相似环境的目的

相似环境模块回答：

> 过去哪些历史起点与今天最接近？这些起点之后的 1M、3M、6M 路径如何？

它不是收益预测器，也不是买卖信号。报告会展示样本日期、距离、forward return、3M 最大回撤、路径分位数和独立历史阶段数。

## 加权标准化距离

每个历史候选日期只使用该日期当时已经可见的信息：

```text
distance = sqrt(
    sum(weight_i * ((current_i - historical_i) / scale_i)^2)
    / sum(weight_i)
)
```

- 距离越低，历史起点越接近当前环境
- `scale` 把不同单位转换为可比较尺度
- `weight` 提高关键变量的解释权重
- 缺失特征会被剔除，不会使用虚构值补齐
- 有效特征覆盖率低于 `65%` 的历史样本不会进入候选池

输入覆盖 ETF 自身结构和跨资产环境：新增仓位环境分数、拥挤度、RSI、动量、距 SMA50/200、`σ200`、波动率、SPY、QQQ、VIX、DXY、10Y yield、黄金和油价。

## 为什么分数 scale 是 15

新增仓位环境分数本身是 `0-100`。相似度公式中的 `scale=15` 不是评分上限，而是“有意义的差异单位”。

例如，当前分数为 `75`，历史日期分数为 `60`：

```text
(75 - 60) / 15 = 1
```

表示两者在这个特征上相差一个标准化尺度。相似度公式才能把百分制分数、VIX 点数、收益率变化和 RSI 放进同一距离框架。

## MAD 自适应校准

MAD 是 Median Absolute Deviation，中位绝对偏差：

```text
median = 中位数(x)
MAD = 中位数(abs(x - median))
robust_scale = 1.4826 * MAD
```

`1.4826` 用于让 MAD 在近似正态分布下与标准差具有可比尺度。

为什么不直接使用普通标准差：高波动主题 ETF 经常出现少量极端单日涨跌。普通标准差容易被极端值拉大，使很多本来差异明显的环境看起来过度相似。MAD 更关注分布中间部分，因此更稳健。

例子：

```text
历史动量：4, 5, 5, 6, 6, 7, 28
中位数：6
绝对偏差：2, 1, 1, 0, 0, 1, 22
MAD：1
```

极端值 `28` 不会主导尺度。实际运行中，自适应尺度限制在预设基准的 `0.5x-2x`，避免样本太少或分布过平导致尺度失真。

## 持仓回撤使用的稳健历史波动率

持仓面板中的“回撤约多少 `σ(1M)`”、黄色观察阈值和红色观察阈值，不直接使用某一个交易日的涨跌幅，也不使用上文相似环境模块的 MAD。系统使用 ETF 或股票自身的历史日收益率，按以下步骤估算稳健日波动率：

1. 根据相邻收盘价计算日收益率：

```text
daily_return_t = (close_t / close_(t-1) - 1) * 100
```

2. 分别读取最近 `63`、`126` 和 `252` 个交易日窗口。每个窗口至少需要 `30` 个有效样本。

3. 在每个窗口内，将低于 `5%` 分位数的收益率替换为 `5%` 分位数，将高于 `95%` 分位数的收益率替换为 `95%` 分位数。这一步称为 Winsorize：

```text
clipped_return = min(max(daily_return, q05), q95)
```

4. 对每个窗口去极值后的收益率计算样本标准差：

```text
winsorized_std =
    sqrt(sum((clipped_return - mean(clipped_return))^2) / (n - 1))
```

5. 取三个有效窗口估计值的中位数，作为稳健日波动率：

```text
robust_daily_vol =
    median(winsorized_std_63d, winsorized_std_126d, winsorized_std_252d)
```

采用多窗口中位数有两个目的：

- 避免单日异常涨跌将波动率估计短期拉高，从而掩盖真实回撤风险
- 同时兼顾季度、半年和一年尺度，避免只依赖某一个窗口的偶然状态

系统再将稳健日波动率转换为约一个月的波动尺度：

```text
robust_monthly_vol = robust_daily_vol * sqrt(21)
pullback_multiple_1m = abs(drawdown_from_year_high) / robust_monthly_vol
```

其中：

- `drawdown_from_year_high` 是当前价格相对年内高点的回撤百分比
- `21` 代表约一个月的交易日数量
- 黄色观察阈值为 `max(5%, 1 × robust_monthly_vol)`
- 红色观察阈值为 `max(10%, 2 × robust_monthly_vol)`

报告中的“回撤约 `2.81σ(1M)`”表示：当前年内高点回撤约等于该资产稳健月度波动尺度的 `2.81` 倍。它用于跨资产比较回撤严重程度，不是严格统计学 z-score：年内高点回撤属于路径依赖指标，而不是单一月份收益率。更准确的理解是“月度正常波动倍数”。

## 两套稳健方法的区别

| 方法 | 使用位置 | 目的 |
| --- | --- | --- |
| `1.4826 × MAD` | 相似环境距离 | 防止少量历史极端值扭曲特征标准化尺度 |
| `63/126/252` 日 Winsorized 标准差的中位数 | 持仓回撤、月度波动倍数、趋势偏离 | 防止单日异常行情掩盖持仓回撤风险 |

## 防止未来信息泄漏

历史 ETF 特征严格使用：

```text
history[: historical_index + 1]
```

跨资产特征也只读取该历史日期或之前最近一个有效交易日。未来 1M/3M/6M 收益和 3M 回撤只在相似度排序完成后作为 outcome 读取。

尾部案例标签和历史事件线索同样只在匹配完成后用于复盘，不参与距离计算。因此系统是“先按当时已知信息匹配，再看后来发生了什么”，而不是“先找到后来下跌的日期，再倒推筛选变量”。

## 独立历史阶段

相邻周度记录可能来自同一轮行情。系统会将相邻不超过 28 天、阶段总跨度不超过 63 天的样本聚类，并用距离最低的记录代表该阶段。这样不会把一轮上涨行情重复计数十次。

## 尾部案例

尾部案例用于显示相似历史环境中的脆弱路径：

- 未来 6M 收益为负
- 或未来 3M 最大回撤达到 `-5%` 或更深
- 或 1M/3M/6M 收益全部为负

历史事件线索用于复盘，不是单一因果归因，也不表示当前市场将机械复制历史路径。

这里的最大回撤不是“3M 总收益”。它表示未来 3 个月路径中，从阶段内局部高点到之后低点的最深跌幅，因此以负数显示。例如 `-8%` 比 `-5%` 更深。即使 3M 最终收益为正，期间仍可能先经历明显回撤。

## 市场冲击历史类比

紧急市场冲击模块触发后，报告会额外展示“市场冲击历史类比”。它回答的问题是：

> 今天已经出现了明显大跌或波动率冲击，过去类似的冲击日之后，1D、5D、20D 路径大致如何？

这不是预测器，也不是抄底或止损信号。它只用于把当天的冲击放回历史分布中，帮助判断“今天像不像过去的普通波动、波动率扩散，还是更接近尾部窗口”。

### 触发逻辑

历史类比不会每天运行展示，只有紧急冲击 alert 触发时才进入报告。当前使用的触发条件与紧急邮件一致，核心包括：

- Nasdaq 100、S&P 500 或 Russell 2000 单日明显下跌
- VIX 或 VVIX 单日快速上行
- 美元走强与权益下跌共振
- 多个较弱信号叠加后形成组合冲击

不是所有单一指标轻微触发都会发警报。系统会把每个触发项映射为 severity，若存在硬触发，或多个信号合计达到阈值，才认为市场冲击成立。

### 相似度如何计算

市场冲击类比只使用候选日当时已经可见的当日变化，不使用未来收益参与匹配。当前特征包括：

| 特征 | 解释 | 标准化尺度 |
| --- | --- | --- |
| Nasdaq 100 当日涨跌幅 | 高久期成长资产压力 | `1.6%` |
| S&P 500 当日涨跌幅 | 大盘风险偏好 | `1.1%` |
| Russell 2000 当日涨跌幅 | 小盘与融资条件敏感度 | `1.6%` |
| VIX 当日变化 | 权益波动率扩散 | `10%` |
| VVIX 当日变化 | 波动率的波动率、尾部保护需求 | `8%` |
| DXY 当日变化 | 美元流动性与全球风险偏好压力 | `0.35%` |

距离公式为：

```text
distance = sqrt(mean(((current_i - historical_i) / scale_i)^2))
```

距离越低，说明候选历史日与当前冲击越接近。若某个历史日缺少太多特征，系统会剔除该样本；有效特征覆盖率低于 `55%` 的样本不会进入候选池。

### 防止未来信息泄漏

匹配步骤只读取历史日当天及以前的数据：

```text
historical_features = same_day_change(historical_day)
```

未来 `1D/5D/20D` 收益和回撤只在样本已经按距离排序之后作为 outcome 读取：

```text
match first, then read forward path
```

因此系统不是先找未来大跌的日子再倒推特征，而是先用当天已知信息匹配，再复盘这些样本后来发生了什么。

### 独立历史阶段

连续几天的冲击往往来自同一轮行情。系统会把相邻不超过 `5` 天的相似样本聚合为同一个独立阶段，并选距离最低的一天作为代表样本。这样可以避免把同一轮暴跌或反弹重复计数，让“历史样本数”看起来虚高。

### 尾部路径

尾部路径用于提示“类似冲击后出现进一步风险释放”的历史比例。当前判定包括：

- 未来 `5D` 收益为负
- 或未来 `5D` 最大回撤达到 `-5%` 或更深
- 或未来 `20D` 收益低于 `-3%`
- 或未来 `20D` 最大回撤达到 `-8%` 或更深

这里的“达到 `-5%` 或更深”指回撤幅度更大，例如 `-8%` 比 `-5%` 更严重。它不是概率预测，只是对相似历史阶段的路径分布做风险复核。
